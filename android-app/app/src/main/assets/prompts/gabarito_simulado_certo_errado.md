# PROMPT — GABARITO C/E DATAPREV + DIAGNÓSTICO + SOLEM

Use este prompt depois de concluir o simulado DATAPREV no formato **CERTO/ERRADO**.

O simulado deve estar disponível nesta conversa. Se já estiver, não peça para reenviar.

Atue como:

1. corretor rigoroso especializado no conteúdo do edital DATAPREV;
2. especialista em questões FGV adaptadas para C/E;
3. analista de desempenho;
4. classificador das questões por disciplina e tópico do edital;
5. gerador dos dados para importação no Sistema Solem.

# 2. COMO RESPONDER

Para cada questão informe:

`Questão | Resposta | Confiança | Tempo`

Exemplo:

`01 | C | 3 | 00:45`

Respostas:

- `C` = Certo
- `E` = Errado

Também aceite:

- `V` como `C`
- `F` como `E`

Confiança:

- `3` = certeza
- `2` = dúvida
- `1` = chute ou dúvida forte

Tempo:

`mm:ss`

**Minha resposta:** C/E  
**Gabarito:** C/E  
**Confiança:** 1/2/3  
**Tempo:** mm:ss  
**Disciplina:**  
**Tópico do edital:**  

**Explicação:** explique de forma simples e direta por que a assertiva está certa ou errada.

# 5. CLASSIFICAÇÃO

Use somente estas disciplinas:

- `Atualidades e IA`
- `Banco de Dados (SQL/NoSQL/Big Data)`
- `Ciência de Dados (ML/DL/PLN/Visão)`
- `Legislação (LAI/Marco Civil/LGPD)`
- `Linguagens (Python/R/Spark/SAS)`
- `Língua Inglesa`
- `Língua Portuguesa`
- `Matemática e Estatística Aplicada`
- `Raciocínio Lógico`

Escolha apenas **um tópico principal do edital por questão**.

Use o tópico mais específico possível.

---

# 6. TIPO DE ERRO

Para cada questão errada, classifique o principal motivo como:

- `Conceitual`
- `Cálculo`
- `Interpretação`
- `Atenção`
- `Confusão entre conceitos`
- `Desconhecimento factual`
- `Estratégia`

Considere especialmente:

**Falsa certeza:** erro com confiança 3.

**Acerto instável:** acerto com confiança 1.

**Dúvida produtiva:** acerto com confiança 2.

**Domínio forte:** acerto com confiança 3.

# 7. DIAGNÓSTICO FINAL

Após corrigir tudo, apresente:

1. total de acertos, erros e anuladas;
2. percentual geral;
3. percentual do Módulo I;
4. percentual do Módulo II;
5. desempenho por disciplina;
6. desempenho por tópico;
7. tempo médio por questão;
8. quantidade de falsas certezas;
9. quantidade de acertos instáveis;
10. principais tipos de erro;
11. tópicos mais fracos;
12. tópicos mais fortes;
13. cinco prioridades de estudo;
14. plano de revisão para os próximos 7 dias;
15. avaliação do meu nível atual.

Não considere apenas percentual de acertos. Cruze:

**acerto + confiança + tempo + dificuldade + tipo de erro.**

---

# 8. ANÁLISE C/E

Mostre também:

- quantidade de respostas `C`;
- quantidade de respostas `E`;
- quantidade real de itens `C`;
- quantidade real de itens `E`.

Informe se tenho tendência excessiva a marcar `C` ou `E`.

Também mostre:

- itens que eram `E` e marquei `C`;
- itens que eram `C` e marquei `E`.

Isso ajuda a identificar se tenho dificuldade maior em:

- detectar pequenas falsidades;
- ou desconfiar de afirmações verdadeiras.

---

# 9. PONTUAÇÃO

Pontuação principal:

- correta = 1
- errada = 0
- anulada = desconsiderada

Calcule:

\[
Aproveitamento = \frac{Acertos}{Questões\ válidas}\times100
\]

Como informação adicional, calcule também o saldo hipotético estilo CEBRASPE:

\[
Saldo = Acertos-Erros
\]

Não use esse saldo como minha nota principal.

---

# 10. IMPORTAÇÃO SOLEM

Ao FINAL da resposta gere obrigatoriamente o bloco de importação.

Ele deve ser a última parte da resposta.

Não escreva nada depois dele.

Use JSON válido e sem comentários.

Estrutura:

SOLEM_IMPORT_START
{
  "schema": "solem_simulado_ce_v1",
  "simulado_id": "DATAPREV-CE-SIM-001",
  "data": "2026-09-02",
  "fonte": "IA (FGV adaptado C/E)",
  "formato": "C/E",
  "questoes": [
    {
      "numero": 1,
      "disciplina": "Língua Portuguesa",
      "topico_edital": "1 Compreensão e interpretação de textos de gêneros variados",
      "resposta_usuario": "C",
      "gabarito": "E",
      "resultado": "errada",
      "tempo_segundos": 45,
      "tempo_informado": true,
      "confianca": 3,
      "tipo_erro": "Atenção"
    }
  ]
}
SOLEM_IMPORT_END

Regras:

- converter `mm:ss` para segundos;
- `resultado` = `correta`, `errada` ou `anulada`;
- `resposta_usuario` = `C` ou `E`;
- `gabarito` = `C`, `E` ou `ANULADA`;
- usar `null` em `tipo_erro` quando a questão estiver correta;
- não omitir nenhuma questão respondida;
- manter disciplina e tópico em todas as questões;
- garantir que o JSON seja válido.

Antes de finalizar, confira silenciosamente se:

- número de questões está correto;
- acertos e erros batem com o relatório;
- tempos foram convertidos corretamente;
- não existem questões duplicadas;
- o JSON é válido.

Agora aguarde minhas respostas. Se elas já estiverem disponíveis na conversa, inicie a correção imediatamente.

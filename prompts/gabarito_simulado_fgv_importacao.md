# PROMPT — GABARITO FGV COM TEMPO POR QUESTÃO E IMPORTAÇÃO NO SISTEMA SOLEM

Use este prompt **depois de concluir o simulado FGV**. O simulado completo deve estar disponível nesta conversa. Se não estiver, peça que eu o envie antes de iniciar a correção.

Você atuará simultaneamente como:

1. corretor rigoroso da banca FGV;
2. especialista no edital DATAPREV — Analista de TI, perfil Inteligência da Informação;
3. analista de desempenho;
4. classificador de cada questão por disciplina e tópico exato do edital;
5. gerador de dados estruturados para importação no Sistema Solem.

Não invente respostas, tempos ou classificações. Caso algum campo indispensável não tenha sido preenchido, identifique a pendência antes de corrigir.

# 2. COMO PREENCHER

Para cada questão, informe:

- **Resposta:** A, B, C, D ou E;
- **Confiança:** 1, 2 ou 3;
- **Tempo:** minutos e segundos no formato `mm:ss`;
- **Marcação opcional:** `?`, `C`, `!!` ou `nenhuma`.

Escala de confiança:

- `3`: certeza;
- `2`: dúvida entre alternativas;
- `1`: chute ou dúvida forte.

Exemplo:

`01 | B | 2 | 02:35 | ?`

O tempo deve representar somente o período gasto naquela questão. Use `00:00` apenas quando realmente não houver medição.

# 4. REGRAS DA CORREÇÃO

Corrija todas as questões com base no simulado presente na conversa.

Para cada questão:

1. informe o gabarito correto;
2. classifique minha resposta como correta ou errada;
3. explique objetivamente o fundamento;
4. explique a pegadinha da FGV, quando houver;
5. identifique a disciplina;
6. identifique **um único tópico principal e específico do edital**;
7. preserve exatamente o tempo informado;
8. considere confiança e marcações na análise.

Quando uma questão envolver mais de um assunto, escolha como tópico principal aquele sem o qual a questão não poderia ser resolvida. Não use `Simulado / Visão Geral`, `Geral`, `Diversos` ou descrições genéricas.

Use obrigatoriamente um destes nomes de disciplina, sem abreviar ou alterar:

- `Atualidades e IA`
- `Banco de Dados (SQL/NoSQL/Big Data)`
- `Ciência de Dados (ML/DL/PLN/Visão)`
- `Legislação (LAI/Marco Civil/LGPD)`
- `Linguagens (Python/R/Spark/SAS)`
- `Língua Inglesa`
- `Língua Portuguesa`
- `Matemática e Estatística Aplicada`
- `Raciocínio Lógico`

No campo `topico_edital`, copie literalmente o item específico do edital apresentado no prompt que gerou o simulado. Não una tópicos com vírgulas.

# 5. INSIGHTS OBRIGATÓRIOS

Depois da correção individual, produza:

1. nota total e nota ponderada;
2. aproveitamento por disciplina;
3. aproveitamento por tópico;
4. tempo médio por questão;
5. tópicos com pior relação entre tempo e acerto;
6. questões corretas excessivamente demoradas;
7. erros rápidos que indiquem falsa certeza;
8. erros conceituais, de interpretação, cálculo, atenção ou estratégia;
9. falsas certezas: erros com confiança 3;
10. acertos instáveis: acertos com confiança 1 ou 2;
11. cinco prioridades de estudo;
12. plano objetivo de correção para sete dias;
13. conclusão rigorosa sobre o nível competitivo atual.

Não trate rapidez isoladamente como domínio. Não trate demora isoladamente como desconhecimento. Cruze resultado, tempo, confiança e natureza da questão.

# 6. BLOCO OBRIGATÓRIO PARA IMPORTAÇÃO

Ao terminar todo o relatório, gere o bloco abaixo. Ele deve ser a **última parte da resposta**.

Regras técnicas:

- gere JSON válido;
- não use comentários;
- não use reticências;
- não omita nenhuma questão respondida;
- não use bloco Markdown com três crases;
- converta `mm:ss` para segundos inteiros;
- use `resultado` somente como `correta` ou `errada`;
- use a resposta final do usuário em `resposta_usuario`;
- use `A`, `B`, `C`, `D` ou `E` em `gabarito`;
- preserve o número original da questão;
- informe `tempo_informado` como `true` quando o usuário tiver preenchido o tempo e `false` quando estiver ausente;
- repita o identificador e a data preenchidos pelo usuário;
- a lista `questoes` deverá conter um objeto para cada questão.

Estrutura obrigatória:

SOLEM_IMPORT_START
{
  "schema": "solem_simulado_v1",
  "simulado_id": "FGV-DATAPREV-2026-SIM-001",
  "data": "2026-08-30",
  "fonte": "IA (Estilo FGV)",
  "questoes": [
    {
      "numero": 1,
      "disciplina": "Língua Portuguesa",
      "topico_edital": "1 Compreensão e interpretação de textos de gêneros variados",
      "resposta_usuario": "B",
      "gabarito": "B",
      "resultado": "correta",
      "tempo_segundos": 155,
      "tempo_informado": true,
      "confianca": 2,
      "marcacao": "?"
    }
  ]
}
SOLEM_IMPORT_END

Antes de encerrar, valide silenciosamente:

- quantidade de objetos no JSON igual à quantidade de questões corrigidas;
- números sem repetição;
- soma dos tempos das questões igual ao tempo efetivamente informado;
- totais de corretas e erradas iguais aos apresentados no relatório;
- disciplina e tópico presentes em todas as questões;
- JSON sintaticamente válido.

Agora aguarde o preenchimento dos dados e das 70 respostas antes de iniciar a correção.
